# QMT 报错搜不到？因为该按「现象」查，不是按「报错原文」

QMT 的报错文案因券商客户端版本差别很大，**搜原文基本搜不到东西**。按现象对页才有效。

| 你看到的 | 先看 |
| --- | --- |
| `get_full_tick` / 盘口为空 | 拿不到实时行情 |
| 下单返回了但没成交 / 废单 | `passorder` 未成交 |
| 不知道委托成没成 | 委托回调怎么写 |
| 持仓 / 资金查不到 | 怎么获取持仓 |
| 回测能跑、实盘歪 | 回测和实盘不一样 |
| `run_time` 回测没日志 | `run_time` 回测不跑 |
| `SyntaxError` | 源码第一行加 `#coding:gbk` |
| `not in whitelist` | 自装库不在券商白名单，找营业部 |

**通用排查顺序**：①是不是在策略交易界面跑、账号绑上没 ②后缀和账号类型对不对 ③这个函数在当前模式支不支持 ④`passorder` 对着手册枚举填，别凭记忆。

按现象查的完整索引：https://www.kimiquant.cn/problems/
