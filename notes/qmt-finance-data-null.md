# 财务数据取到空值：先分清「字段不存在」和「值确实为空」

财务数据**不是行情数据**，它的更新节奏按报告期走，不按 tick 走。所以「取到空」在很多情况下是正常的，不是接口坏了。

## 一、先把完整返回结构打印出来

不要只打印你想要的那个字段。

- 字段名**不在**返回结构里 → 字段名写错，或该版本没有这个字段
- 字段**在**、但值是 `NaN` → 数据侧的问题

最常见的错法是字段名从几年前的博客里抄来的。各家客户端的财务字段命名一直在变，**抄来的字段名不可信**。

## 二、财务数据是「报告期」数据，非披露期本来就空

财务数据的语义是「截止某个报告期、在某天公告」。所以：

- 查询日期落在**非交易日**，按日期模式取数会返回空值——这是文档里明确写的规则，不是异常
- 报告期还没披露，自然是空的
- 盘中取当日数据，当日尚未更新，同样返回空

正确做法是**传入上一个交易日**作为日期参数，而不是用当前时间。

⚠️ 回测和实盘表现还不一样：回测中甚至可能取到未来数据，需要自己规避。

## 三、单季和累计，是两个不同的口径

同一个「净利润」，有的接口给的是**单季值**，有的给的是**年初至今累计值**。

用错口径不会报错，只会算出一个看起来很合理、但完全不对的数。从聚宽搬到别的平台时这个问题尤其突出——聚宽那边习惯单季，换平台后拿到累计值，选股结果直接偏掉。

## 四、权限

部分财务字段需要券商侧开通对应权限，没开通就是空。这类空值和「字段不存在」长得一样，只能靠打印返回结构来区分。

## 排查顺序

1. 打印完整返回结构，确认字段名到底在不在
2. 确认传入的日期是**交易日**，且不是当日盘中
3. 确认拿的是单季还是累计，和策略假设对齐
4. 确认该字段是否需要额外权限
